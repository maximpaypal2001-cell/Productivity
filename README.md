# Учёт самозанятого

Веб-приложение для учёта доходов и расходов самозанятого, который покупает и
перепродаёт товары. Хранит покупки, продажи, расходы и документы в одном
месте, считает прибыль по каждому товару и формирует отчёт для налоговой
декларации.

## Возможности

- **Товары.** Фиксируете покупку: название, категория, марка/модель, дата,
  сумма, где куплено, чек/фото. Когда товар продан — открываете ту же
  карточку и отмечаете продажу: дата, сумма, где продали, покупатель, чек.
  Приложение само считает прибыль (продажа минус покупка).
- **Расходы.** Прочие расходы бизнеса, не привязанные к товару: упаковка,
  доставка, реклама и т.д., тоже с чеками.
- **Документы.** Личное хранилище любых файлов, связанных с самозанятостью
  (регистрация, справки, договоры).
- **Отчёты.** Сводка за месяц/год/произвольный период: выручка,
  себестоимость, прибыль, оценка налога; выгрузка в CSV (открывается в
  Excel) — удобно передать бухгалтеру или свериться перед подачей
  декларации.
- **Личный кабинет.** Один аккаунт с email и паролем, ставка налога для
  оценки задаётся в профиле.

## Запуск локально

Понадобится [Node.js](https://nodejs.org/) версии 20 или новее.

```bash
npm install
npm run dev
```

`npm install` сам создаст файл `.env` со случайным ключом и подготовит базу
данных — ничего вручную настраивать не нужно. После `npm run dev` откройте
<http://localhost:3000> — при первом заходе приложение попросит создать
аккаунт (email и пароль). Дальше просто заходите под этим паролем.

Все данные хранятся локально:

- база данных — `prisma/dev.db`;
- загруженные файлы (чеки, документы) — `data/uploads/`.

Обе папки не попадают в git (см. `.gitignore`) — это ваши личные данные.

### Сборка для продакшена

```bash
npm run build
npm start
```

## Перенос в облако

Когда будете готовы открыть доступ с телефона и с компьютера одновременно,
это то же самое приложение — просто нужно развернуть его на сервере с
постоянным диском (например, обычный VPS, или любой хостинг с поддержкой
persistent volume для Node.js-приложений):

1. Разверните проект и задайте переменные окружения `DATABASE_URL` и
   `AUTH_SECRET` (второй — длинная случайная строка, держите в секрете).
2. Выполните `npm install`, `npm run build`, затем `npm start`.
3. При желании перейти с SQLite на PostgreSQL — поменяйте `provider` в
   `prisma/schema.prisma` на `postgresql` и `DATABASE_URL` на адрес базы,
   затем `npx prisma migrate deploy`.
4. Заходите с телефона и компьютера по адресу сервера — данные будут общие,
   один и тот же аккаунт.

## Технологии

Next.js (React) + TypeScript, Prisma + SQLite, Tailwind CSS. Файлы хранятся
на диске сервера, доступ к ним — только из-под своего аккаунта.
