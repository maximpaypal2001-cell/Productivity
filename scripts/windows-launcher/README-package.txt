УЧЁТ САМОЗАНЯТОГО — как запустить
==================================

1. Распакуйте этот архив целиком в любую папку (например, на Рабочий стол).
   Важно: не переносите файлы по отдельности — "Запустить.vbs" использует
   папки node и app рядом с собой.

2. Дважды щёлкните "Запустить.vbs".

   Ничего видимого не откроется несколько секунд — это нормально, программа
   в этот момент запускается в фоне. Затем сам откроется браузер с
   приложением. Устанавливать Node.js или что-либо ещё не нужно — всё уже
   внутри архива.

   Windows может показать предупреждение SmartScreen ("Windows защитила
   ваш компьютер") — это стандартная реакция на новую программу без
   цифровой подписи, вирусов в ней нет. Нажмите "Подробнее", затем
   "Выполнить в любом случае".

3. При первом запуске приложение попросит создать аккаунт (email и
   пароль) — это ваш личный кабинет, он будет единственным в программе.

4. Программа продолжает работать в фоне, даже если закрыть окно браузера
   (чтобы зайти снова — откройте http://localhost:3000 или ещё раз
   запустите "Запустить.vbs", он просто откроет браузер заново).

   Чтобы ПОЛНОСТЬЮ ОСТАНОВИТЬ программу — запустите "Остановить.bat".

Где хранятся ваши данные
-------------------------
Всё лежит внутри папки app:
  app\prisma\dev.db      — база данных (товары, продажи, расходы)
  app\data\uploads        — загруженные чеки и документы

Хотите сделать резервную копию — скопируйте всю папку целиком в другое
место (например, на флешку или в облачное хранилище).

Если что-то пошло не так
-------------------------
Откройте файл launcher.log (появляется рядом с "Запустить.vbs" после
первого запуска) — там будет видно, в чём проблема. Если программа не
откроется за 30 секунд, появится всплывающее окно с сообщением об этом.
