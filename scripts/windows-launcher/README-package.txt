УЧЁТ САМОЗАНЯТОГО — как запустить
==================================

1. Распакуйте этот архив целиком в любую папку (например, на Рабочий стол).
   Важно: не переносите файл "Запустить.exe" отдельно от папок node и app —
   он их использует.

2. Дважды щёлкните "Запустить.exe".

   Windows может показать предупреждение "Windows защитила ваш компьютер"
   (SmartScreen) — это стандартная реакция на новую программу без
   цифровой подписи, вирусов в ней нет. Нажмите "Подробнее", затем
   "Выполнить в любом случае".

   Откроется чёрное окно консоли — это нормально, программа так
   показывает, что происходит. НЕ ЗАКРЫВАЙТЕ его, пока пользуетесь
   приложением: оно держит сервер запущенным. Через несколько секунд
   само откроется окно браузера с программой.

3. При первом запуске приложение попросит создать аккаунт (email и
   пароль) — это ваш личный кабинет, он будет единственным в программе.

4. Чтобы закрыть программу — закройте то самое чёрное окно консоли.
   Чтобы открыть снова — просто ещё раз запустите "Запустить.exe".

Где хранятся ваши данные
-------------------------
Всё лежит внутри папки app:
  app\prisma\dev.db     — база данных (товары, продажи, расходы)
  app\data\uploads       — загруженные чеки и документы

Хотите сделать резервную копию — скопируйте всю папку целиком в другое
место (например, на флешку или в облачное хранилище).

Если что-то пошло не так
-------------------------
Откройте файл launcher.log (появляется рядом с "Запустить.exe" после
первого запуска) — там будет видно, в чём проблема. Пришлите мне его
содержимое, и я разберусь.

Программа сделана и однократно протестирована на Linux (эмуляцией того
же кода) — на реальном Windows я её не запускал, так как у меня его нет
под рукой. Если при первом запуске что-то не сработает — не страшно,
просто напишите мне, что именно произошло, и я быстро поправлю.
